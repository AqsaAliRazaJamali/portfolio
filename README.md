## 📂 Featured Projects
 
### 🔹 CareerMint – AI Resume Builder *(Team Project)*
MERN stack-based AI resume builder with content enhancement, PDF parsing, live preview, JWT authentication, and MongoDB-backed resume management. Built with Redux Toolkit for state management and a polished Tailwind CSS UI.
 
### 🔹 Privacy-First Local PDF Toolkit
A fully air-gapped browser PDF workspace with 8 operational modules — merge, split, rotate, AES-256 password protection, watermarking, compression, text extraction, and canvas-driven page previews. 100% client-side processing via `pdf-lib` and `pdfjs-dist`. No file uploads, no server storage. → [Live App](https://vercel.com/aqsa-jamali-s-projects/pdf-toolkit)
 
### 🔹 AI Study Assistant
Multi-model learning platform built with Python and Streamlit. Upload PDF/Word documents and interact with them using Gemini Pro or Groq. Features a 4-node workspace: AI Tutor, Notes Synthesizer, Assessment Engine, and Concept Explainer with 4 complexity depths. → [Live App](https://ai-study-assistant-aqsa.streamlit.app)
 
### 🔹 Intelligent Email Studio
AI-powered communication workspace using a resilient Gemini 2.5 Flash + Groq Llama 3.1 failover architecture. Analyzes emails into structured metadata, drafts professional replies across 5 tones, and handles smart thread responses. → [Live App](https://intelligent-email-studio.streamlit.app)
 
### 🔹 ML Studio Visualizer
Interactive React + Vite app demonstrating core ML algorithms in real time — live Linear Regression with Gradient Descent, MSE tracking, and K-Means Clustering with adjustable K, learning rate, and epoch controls. → [GitHub](https://github.com/aqsaalirazajamali/ml-visualizer)
 
### 🔹 SecurePass Studio
Enterprise-grade password generation platform using the Web Crypto API for cryptographically secure randomness, entropy analysis, leet-speak hardening, and session history — 100% client-side with zero data transmission. → [GitHub](https://github.com/aqsaalirazajamali/securepass-studio)
